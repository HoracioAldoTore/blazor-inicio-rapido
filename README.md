# blazor-inicio-rapido
Curso de Introducción a Blazor guiado por componetes. Del mas sencillo al mas complejo.

Temario:
<ol>
  <li><b>Primer Componente</b> (Estructura básica de un .razor, marco visual para <code>reutilizar y encapsular</code>).</li>
  <li><b>Parametros</b> (Comunicación de datos desde el padre hacia el hijo con <code>[Parameter]</code>).</li>
  <li><b>Metodos</b> (Lógica interna del componente e invocación de métodos vía <code>@ref</code>).</li>
  <li><b>Eventos Estándar</b> (Manejo de eventos del navegador como <code>@onclick</code>).</li>
  <li><b>Eventos Personalizados</b> (Notificación hacia el padre utilizando <code>EventCallback</code>).</li>
  <li><b>Renderizado Condicional</b> (Control de la interfaz usando estructuras <code>@if / @else</code>).</li>
  <li><b>Enlace Bidireccional</b> (Sincronización de datos mediante <code>@bind</code>).</li>
  <li><b>Componentes Contenedores</b> (Reutilización avanzada de interfaz con <code>RenderFragment</code> y <code>ChildContent</code>).</li>
</ol>
