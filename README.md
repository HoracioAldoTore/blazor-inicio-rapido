# blazor-inicio-rapido
Curso de Introducción a Blazor guiado por componetes. Del mas sencillo al mas complejo.

Temario:
<ol>
  <li><b>01-Primer Componente</b> (Estructura básica de un .razor, marco visual para reutilizar y encapsular).</li>
  <li><b>02-Parametros</b> (Comunicación de datos desde el padre hacia el hijo con <code>[Parameter]</code>).</li>
  <li><b>03-Metodos</b> (Lógica interna del componente e invocación de métodos vía <code>@ref</code>).</li>
  <li><b>04-Eventos Estándar</b> (Manejo de eventos del navegador como <code>@onclick</code>).</li>
  <li><b>05-Eventos Personalizados</b> (Notificación hacia el padre utilizando <code>EventCallback</code>).</li>
  <li><b>06-Renderizado Condicional</b> (Control de la interfaz usando estructuras <code>@if / @else</code>).</li>
  <li><b>07-Enlace Bidireccional</b> (Sincronización de datos mediante <code>@bind</code>).</li>
  <li><b>08-Componentes Contenedores</b> (Reutilización avanzada de interfaz con <code>RenderFragment</code> y <code>ChildContent</code>).</li>
</ol>
