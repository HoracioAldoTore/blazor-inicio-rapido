# blazor-inicio-rapido
Curso de Introducción a Blazor guiado por componetes. Del mas sencillo al mas complejo.

Temario:
1.	01-Primer Componente
(Estructura básica de un .razor, marco visual para reutilizar y encapsular).
2.	02-Parametros
(Comunicación de datos desde el padre hacia el hijo con [Parameter]).
3.	03-Metodos
(Lógica interna del componente e invocación de métodos vía @ref).
4.	04-Eventos Estándar
(Manejo de eventos del navegador como @onclick).
5.	05-Eventos Personalizados
(Notificación hacia el padre utilizando EventCallback).
6.	06-Renderizado Condicional
(Control de la interfaz usando estructuras @if / @else).
7.	07-Enlace Bidireccional
(Sincronización de datos mediante @bind).
8.	08-Componentes Contenedores
(Reutilización avanzada de interfaz con RenderFragment y ChildContent).
